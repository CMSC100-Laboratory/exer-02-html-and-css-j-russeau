Steps on how to create a GitHub page:
1. Initialize remote repository in GitHub.
2. Clone remote repository to local repository.
3. Go to cloned repository.
4. Make sure to have personal GitHub credentials available using git config.
5. Make GitHub repository public.
6. Add index.html and flex.css files in local repository and push to remote repository.
7. Go to Pages settings in GitHub repository, and set branch to main. Wait until the live website link is published for you to check.

Key takeaways from this exercise:
1. Flexbox is a very powerful and helpful styling tool for CSS.
2. GitHub Pages provides a meaningful way to have my live website shareable across my peers using GitHub.
